# Hello, Contributors! 👋

First of all, I'm very glad to see you there. I'm feeling your inspiration, so let's start.

This file is a guideline for developers on how to contribute to this project. I've separated the whole process into 4 steps:

2. Setup your working machine.
3. Making updates (contribution itself).
4. Submitting work you've done.
